## figures4papers skill安装

### 项目信息
- 作者：Chen Liu（耶鲁大学计算机科学博士候选人）
- 项目地址：https://github.com/ChenLiu-1996/figures4papers
- 发表论文：Nature Machine Intelligence、ICML、NeurIPS、ECCV
- 功能：学术论文配图（柱状图、热力图、趋势图、雷达图、多面板布局）

### 设计哲学
1. **极简主义** — 去掉不必要的装饰，只保留数据
2. **语义化配色** — 蓝色=自己的方法，红色=基线，金色=高亮
3. **超宽画布+动态坐标轴** — 根据数据真实范围收紧坐标轴
4. **黑白可读+数值标注** — 打印出来也能看

### skill结构
```
figures4papers/
├── SKILL.md                  # 快速参考
└── references/
    ├── api.md                # API/约定（调色板、辅助函数、导出）
    ├── common-patterns.md    # 可复用的图模式
    ├── demos.md              # 实际项目演示
    ├── design-theory.md      # 设计理论和原理
    └── tutorials.md          # 分步教程
```

### 用途
赵9月入学苏州科技大学读研，需要写论文、做数据可视化。这个skill可以直接用于：
- 城乡融合数据的柱状图、热力图
- 乡村振兴研究的趋势图、对比图
- 论文配图符合顶刊标准

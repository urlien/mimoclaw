## 正则表达式教训

### 字符类中的 `-` 必须转义
- jessica_full.html 第 24959 行的正则 `...-\-\...` 被当成范围运算符（`.` 到 `\`）
- 结果：`Range out of order in character class` → 整个 script 块解析失败 → `window.initApp` 未定义 → 白屏
- **修复：** `-` 在字符类中必须转义为 `\-`，或放在字符类末尾
- **教训：** sed/编辑正则后必须用 `node -e "new Function(code)"` 验证语法

### Python 的 compile() 不能检查 JavaScript 语法
- 用 `compile(code, 'file', 'exec')` 检查 JS 代码会报各种假错误
- 正确做法：用 Node.js 的 `new Function(code)` 或 `node --check`

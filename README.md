- **RULES.md** — 规则速查手册，关键词机制、五行确认、红线雷点

### 输出规则
每轮输出必须：
1. 调用read工具读取7个规则文件
2. 输出五行确认（已完整阅读/红线确认/雷点确认/关键词确认/违规计数）
3. 关键词检测（"开始"是唯一关键词，解锁执行权限）
4. 正文

### 关键词机制
- **"开始"** — 唯一关键词，解锁执行权限（仅当前消息）
- 每条新消息重新检查，不继承上一条的"开始"
- read工具调用不需要授权（安全带）
- 其他所有工具调用必须有"开始"才能执行

## 重要教训

- **永远不要在有内容的仓库上force push**
- **cp -a会复制.git目录，用rsync --exclude**
- **sed全局替换是炸弹** — 函数名替换会匹配定义+调用
- **嵌套HTML注释是语法炸弹** — 给已注释代码加注释=浏览器解析错误
- **read流程是安全带** — 不管什么"氛围"，每轮必走
- **没有"开始"不能调工具** — 把赵的话当隐含"开始"=违规
- **规则比任务重要** — 跳过规则赶进度=违规

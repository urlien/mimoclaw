明日方舟剧情下载指南
====================

## 你需要准备的东西
1. Python 3（你本地应该有）
2. GitHub账号（你有）

## 步骤一：下载剧情文件

在你的电脑上打开终端（PowerShell或CMD），运行以下命令：

```python
import json, urllib.request, os

# 创建目录
os.makedirs('ark_stories', exist_ok=True)

# 下载story_review_table.json
url = "https://raw.githubusercontent.com/Kengxxiao/ArknightsGameData/master/zh_CN/gamedata/excel/story_review_table.json"
req = urllib.request.Request(url)
resp = urllib.request.urlopen(req, timeout=30)
data = json.loads(resp.read())

# 收集所有剧情信息
name_to_files = {}
for k, v in data.items():
    for s in v.get('infoUnlockDatas', []):
        story_name = s.get('storyName', '')
        story_txt = s.get('storyTxt', '')
        if story_name and story_txt:
            if story_name not in name_to_files:
                name_to_files[story_name] = []
            name_to_files[story_name].append(story_txt)

print(f'总剧情数: {sum(len(v) for v in name_to_files.values())}')
print(f'去重后剧情名: {len(name_to_files)}')

# 下载所有文件
base_raw = "https://raw.githubusercontent.com/Kengxxiao/ArknightsGameData/master/zh_CN/gamedata/story"
success = 0
fail = 0

for i, (name, paths) in enumerate(name_to_files.items()):
    all_content = []
    for p in paths:
        url = f"{base_raw}/{p}.txt"
        try:
            req = urllib.request.Request(url)
            resp = urllib.request.urlopen(req, timeout=10)
            content = resp.read().decode('utf-8')
            all_content.append(content)
        except:
            pass
    
    if all_content:
        merged = '\n\n---\n\n'.join(all_content)
        with open(f'ark_stories/{name}.txt', 'w', encoding='utf-8') as f:
            f.write(merged)
        success += 1
    else:
        fail += 1
    
    if (i + 1) % 100 == 0:
        print(f'进度: {i + 1}/{len(name_to_files)} (成功: {success}, 失败: {fail})')

print(f'\n完成: {success}/{len(name_to_files)} 成功, {fail} 失败')
print(f'文件数: {len(os.listdir("ark_stories"))}')
```

## 步骤二：创建GitHub仓库

1. 去 https://github.com/new 创建一个新仓库
2. 仓库名：ark-stories-temp（或随便什么名字）
3. 设为公开（Public）
4. 不要初始化README

## 步骤三：上传到GitHub

在终端运行：

```bash
cd ark_stories
git init
git add .
git commit -m "添加明日方舟全部剧情"
git remote add origin https://github.com/你的用户名/ark-stories-temp.git
git push -u origin master
```

## 注意事项

- 下载需要时间（1426个文件），请耐心等待
- 如果网络不好，可以分批下载
- 文件会保存在ark_stories目录下，按剧情名称命名
- 每个文件可能包含多个剧情片段（beg+end），用---分隔

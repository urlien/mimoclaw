# 给 AI Agent 的安装指令：浏览器操控工具（nekoro-browser + PilotBrowseMCP）

请按以下步骤为本机安装两个浏览器自动化工具。它们通过 Chrome 扩展驱动**日常使用的 Chrome**，保留全部登录态，AI 可以打开网页、点击、填表、截图、抓数据，而不会干扰用户自己的浏览器窗口。

## 一、安装 nekoro-browser（首选，轻量通用）

1. 安装：`pip install nekoro-browser`（Python 3.12+，零第三方依赖）
   - Windows 若命令找不到，去 `<Python安装目录>\Scripts\` 找 `nekoro-browser.exe`
2. 验证：`nekoro-browser --version`
3. 获取扩展路径：`nekoro-browser --extension-path`
4. **加载 Chrome 扩展（唯一人工步骤，Chrome 安全限制，无法绕过）**：
   - 请用户打开 `chrome://extensions/` → 右上角开启「开发者模式」→「加载已解压的扩展程序」
   - 选择第 3 步打印的目录（必须选到含 manifest.json 的那一层）
5. 启动 daemon（常驻，保持运行）：单独终端执行 `nekoro-browser`
6. 验证：`nekoro-browser --doctor`（三环全 PASS 即就绪）

**使用方式**：
- 单行：`nekoro-browser -c "await page_info()"`
- 多步：写 UTF-8 无 BOM 的 .py 文件（顶层 await 语句），然后 `cmd /c "type 脚本.py | nekoro-browser"`

常用函数：`new_tab(url)` / `navigate(url)` / `click("text:登录")` / `fill_input(sel, text)` / `state()` / `capture_screenshot()` / `get_markdown()` / `js(code)` / `cdp(...)`

## 二、安装 PilotBrowseMCP（进阶：网络抓包 / JS 逆向 / SQLi 检测）

1. 获取源码：`git clone https://github.com/EndymionLee/PilotBrowseMCP`
   - 或 zip：`curl.exe -sL -o p.zip https://codeload.github.com/EndymionLee/PilotBrowseMCP/zip/refs/heads/master`（zip 仅 ~11MB，放心下）
2. 构建：
   ```bash
   cd server && npm install && npm run build      # tsc → dist/index.js
   cd extension && npm install && npm run build    # vite → dist/
   ```
3. **加载扩展**：`chrome://extensions/` → 开发者模式 →「加载已解压的扩展程序」→ 选 **`extension/dist`**（⚠️ 不是源码目录）
4. 启动 server（常驻）：`node server/dist/index.js`（WebSocket 9456）
5. 验证：`netstat -ano | findstr 9456` 见 ESTABLISHED；日志出现「Extension 已连接」即成功（扩展有自动重连）

## 三、MCP 接入（可选，让工具成为一等公民）

- **Claude Code**：`claude mcp add nekoro-browser -- nekoro-browser-mcp`
  `claude mcp add pilot-browse -- node <绝对路径>/server/dist/index.js`
- **opencode**：`{"mcp": {"nekoro-browser": {"type": "local", "command": ["nekoro-browser-mcp"]}}}`
- **Codex**：`[mcp_servers.nekoro-browser] command = "nekoro-browser-mcp"`
- ⚠️ `mcp add` 交互确认无 TTY 时用管道喂 Y：`cmd /c "echo Y | <你的CLI> mcp add nekoro-browser --command nekoro-browser-mcp"`
- 工具新会话生效，前缀 `mcp_<server>_<tool>`

## 四、实测坑（重要）

1. **Chrome 137+ 禁止 `--load-extension` 注入默认 profile** → 扩展必须手动加载一次，别试命令行注入
2. **Chrome 更新后未打包扩展可能被停用** → chrome://extensions 重新启用
3. **nekoro daemon 是前台进程**，关窗口即停；Windows 自启用「启动文件夹 + vbs 隐藏窗口」：
   ```vbs
   Set WshShell = CreateObject("WScript.Shell")
   WshShell.Run """<Python>\Scripts\nekoro-browser.exe""", 0, False
   ```
   复制到 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\`
4. **PowerShell 管道喂代码带 BOM（U+FEFF）** → 用 `cmd /c "type 文件.py | nekoro-browser"`
5. **MCP 子进程环境是过滤的** → command 用绝对路径最稳
6. 本机参考：Python 在 `D:\Python312`，nekoro 扩展在 `D:\Python312\Lib\site-packages\nekoro_browser\extension`；PilotBrowseMCP 建议放 `D:\PilotBrowseMCP`

## 五、验证清单

- [ ] `nekoro-browser --doctor` 三环全 PASS
- [ ] `echo "await page_info()" | nekoro-browser` 返回 `{"ok": true, ...}`
- [ ] PilotBrowse server 日志出现「Extension 已连接」
- [ ] `netstat -ano | findstr 9456` 有 ESTABLISHED
- [ ] MCP 工具列表出现

**凯西** [2026-08-10T17:32:30]

调音器上显示的"太高"和"太低"是指音高偏了：

- **太高（Sharp/偏高）**：弦绷得太紧，音偏尖了 → 要**松**一点（逆时针拧弦钮）
- **太低（Flat/偏低）**：弦太松，音偏闷了 → 要**紧**一点（顺时针拧弦钮）
- **刚好（绿色/居中）**：音准了

调音的时候慢慢拧，一点一点来，别拧过头。如果调音器显示的字母和目标不一样（比如你要调E，显示的是D），说明差得远，要多拧几圈。

你先试试调6弦（最粗的那根），目标是E。

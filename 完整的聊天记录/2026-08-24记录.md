## 1. 日期区分问题

**根本原因：** 杰西卡用`timestamp`（Date.now()）存储消息时间，用`new Date(m.timestamp).toLocaleDateString('zh-CN')`来分组显示。问题出在**上下文构建**：

```javascript
// 第9801行
ctx += `[${new Date(m.timestamp).toLocaleTimeString('zh-CN',{hour:'2-digit',minute:'2-digit'})}] ${role}: ${m.content}\n`;
```

这里只传了**时间（时:分）**，没传**日期**。所以杰西卡看到的上下文是：
```
[23:00] user: 你好
[23:05] assistant: 你好呀
[23:00] user: 在吗
```

她无法区分第一组"23:00"是昨天的，第二组"23:00"是今天的。

**修复方案：** 在上下文里加上日期前缀，改成：
```javascript
const d = new Date(m.timestamp);
const dateStr = d.toLocaleDateString('zh-CN', {month:'2-digit',day:'2-digit'});
const timeStr = d.toLocaleTimeString('zh-CN',{hour:'2-digit',minute:'2-digit'});
ctx += `[${dateStr} ${timeStr}] ${role}: ${m.content}\n`;
```

这样杰西卡看到的就是：
```
[08/23 23:00] user: 你好
[08/23 23:05] assistant: 你好呀
[08/24 23:00] user: 在吗
```

她就能区分"昨天23点"和"今天23点"了。

## 2. 文件上传问题

**根本原因：** 代码支持PDF/Word/txt/md，但有两个潜在问题：

1. **PDF解析依赖pdf.js动态import**（第19362行），需要网络加载CDN资源。如果网络不好或CDN被墙，import会失败，返回null，然后弹出"文档内容过少或解析失败"。

2. **解析结果检查太严格**（第19765行）：
```javascript
if (!text || text.trim().length < 10) {
  alert('文档内容过少或解析失败');
  return;
}
```
如果PDF是扫描版（图片PDF），pdf.js提取不到文字，返回空字符串，就会报错。

**修复方案：**
- 在parsePDF里加错误提示，区分"网络加载失败"和"PDF无文字内容"

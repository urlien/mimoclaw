一、项目概述
──────────────────────────────────────────────────────────────

杰西卡是一个基于 Web 的 AI 聊天伴侣应用，运行在浏览器中。
项目仓库：https://github.com/urlien/jessica-diary
主文件：jessica_full.html（单文件应用，约 1.2MB，2万行代码）

技术栈：
- 纯 HTML/CSS/JavaScript，无框架依赖
- IndexedDB 存储聊天记录、知识库、设置
- GitHub API 用于云同步（备份到 jessica-data 仓库）
- pdf.js 解析 PDF 文件
- mammoth.js 解析 Word 文件
- 本地 TTS 支持

当前版本：v3.4 "大暑"（2026-07-21 大改版）

三、发现的四个问题
──────────────────────────────────────────────────────────────

【问题1】杰西卡无法区分昨天和今天的聊天

现象：
用户昨天 23 点和杰西卡聊了两句，今天 23 点又聊了两句，
杰西卡会认为这是同一天的聊天，不会区分"昨天的对话"和"今天的对话"。

根本原因：
上下文构建时只传了时间（时:分），没传日期。

相关代码（jessica_full.html 第 9801 行）：
```javascript
ctx += `[${new Date(m.timestamp).toLocaleTimeString('zh-CN',{hour:'2-digit',minute:'2-digit'})}] ${role}: ${m.content}\n`;
```

杰西卡看到的上下文：
```
[23:00] user: 你好
[23:05] assistant: 你好呀
[23:00] user: 在吗        ← 杰西卡认为这还是"23:00"的那个对话
```

修复方案：
在上下文里加上日期前缀：
```javascript
const d = new Date(m.timestamp);
const dateStr = d.toLocaleDateString('zh-CN', {month:'2-digit',day:'2-digit'});
const timeStr = d.toLocaleTimeString('zh-CN',{hour:'2-digit',minute:'2-digit'});
ctx += `[${dateStr} ${timeStr}] ${role}: ${m.content}\n`;
```

修复后杰西卡看到的上下文：
```
[08/23 23:00] user: 你好
[08/23 23:05] assistant: 你好呀
[08/24 23:00] user: 在吗        ← 杰西卡能区分这是"今天23点"
```

复杂度：低（改1行代码）

──────────────────────────────────────────────────────────────

【问题2】PDF/txt 文件上传后无法被杰西卡识别

现象：
上传图片可以正常显示，但上传 PDF 或 txt 文件后，
杰西卡无法识别文件内容，知识库里也没有对应条目。

根本原因：
1. PDF 解析依赖 pdf.js 动态 import（CDN 加载），网络不好会失败
2. 扫描版 PDF（图片PDF）无法提取文字，返回空字符串
3. 解析结果检查太严格，内容过少就弹 alert 阻断

相关代码：
```javascript
// V2DocParser.parsePDF（第19359行）
async parsePDF(file) {
    const pdfjsLib = await import('https://cdn.jsdelivr.net/npm/pdfjs-dist@4.0.379/build/pdf.min.mjs');
    // ... 解析逻辑
}

// addDocument 里的检查（第19765行）
if (!text || text.trim().length < 10) {
    alert('文档内容过少或解析失败');
    return;
}
```

修复方案：
1. 在 parsePDF 里区分"网络加载失败"和"PDF无文字内容"
2. 对扫描版 PDF 提示"这是图片PDF，无法提取文字"
3. 降低最小长度阈值，或改为 toast 提示（不阻断）

复杂度：中（改10-20行代码）

【问题4】首页统计页面被顶部导航栏遮盖

现象：
首页的统计面板（生日倒计时、日历、日记预览等内容）
向上滚动时，内容会被顶部固定定位的导航栏遮盖，
导致用户点不到返回按钮。

根本原因：
统计页面内容区域顶部没有足够的 padding-top，
内容直接从顶部开始渲染，被固定导航栏覆盖。

修复方案：
参考聊天界面的做法，在统计页面内容区顶部加 padding-top，
值等于导航栏高度（大约 50-60px）。

```css
/* 示例 */
.stats-page {
    padding-top: 60px; /* 导航栏高度 */
}
```

复杂度：低（加1行CSS）
